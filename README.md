# algoritmos-greedy-cpp
## Cómo ejecutar el proyecto

Este proyecto fue desarrollado utilizando un entorno de desarrollo integrado (IDE) de C++ (como Code::Blocks).

1. Abre el archivo correspondiente (`Antena.cpp` o `Mochila Fraccional.cpp`) en tu IDE.
2. Asegúrate de que el compilador esté configurado al menos en **C++11** o superior.
3. Presiona el botón de **Build & Run** (Compilar y Ejecutar) o la tecla **F9** para ver el resultado en pantalla.
